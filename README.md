# Happy To-Do updater releases

This public repository hosts signed update packages and the update manifest for Happy To-Do on Windows x64. Application source remains in the private `csx-123/happy-to-do` repository.

The app checks `latest.json` and verifies each package with the public key embedded in the application. Releases are published by the private repository's tagged release workflow. This repository contains update assets only; download the regular installer from the private project's distribution channel.
