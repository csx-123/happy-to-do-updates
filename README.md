# Happy To-Do releases

This public repository hosts Windows x64 installers, checksums, and signed update packages for Happy To-Do. Application source remains in the private `csx-123/happy-to-do` repository.

The app checks the `latest.json` asset and verifies update packages with the public key embedded in the application. Tagged releases are published by the private source repository's release workflow. The regular `.exe` installer and `SHA256SUMS.txt` are also attached for direct downloads.
